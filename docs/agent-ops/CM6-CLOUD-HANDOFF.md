## What is implemented

- `tools/assets/build-recon-pouches.py` authors three mount-local templates: magazine sleeve with retention cord, utility bag with zipper, and radio with antenna/cable owned by the same module. `build-recon-pouches.mjs` runs Blender, optimizes the GLB, checks source hashes and writes catalogue/fit metadata. Editable authoring code is committed; `.blend`, raw GLB and scratch outputs stay ignored.
- `assets/models/operators/recon-pouches.glb` and companion manifest/fit files are committed runtime candidates: magazine 264, utility 220, radio 376 triangles; 860 total template triangles. Six radios plus the complete foundation/carrier allocation total 8,940 triangles. Fabric and trim have woven textures; the optimizer reduces the dark radio material to a flat colour.
- `operator/recon-pouches.json` contains measured CM4 definitions. Each pouch occupies two columns/three rows. `pouch-slots.js` supplies three front and three rear positions, supports repeated item types and uses the existing resolver. Front choices require the placard; rear choices require a carrier. Removing the owner hides its pouches but preserves slot selections for restoration.
- `operator/mounted-pouches.js` captures carrier rest surfaces once, applies asset-rest mount transforms to separate pouch copies, interpolates skin weights from nearby carrier triangles, and binds to the real body bones using rest inverse matrices. It handles compressed/dequantized positions, rear-facing frames, per-instance identity, normalized weights and obsolete-geometry disposal. Mount weight lookups cache matching projected points. It does not rigidly parent all pouches to one bone.
- `operator/operator.js` loads the templates/catalogue with the foundation, updates mounted geometry before applying equipment, reindexes colour materials, and explains disabled pouch controls. `recon-modular.js` adds pouch colour zones and a Patrol carrier preset. Existing URL slot persistence is retained.
- `tests/recon-pouches.test.mjs` covers exported geometry/UVs, budgets, duplicate mounts, overlap rejection, ownership, rest-space placement, posed movement and resource cleanup. `tests/e2e/recon-pouches.mjs` is intended to check 72 carries (3 pouch types × 3 rifles × 8 poses, with six copies fitted) plus removal/save restoration and a contact sheet. Existing clearance helpers now include pouch meshes.

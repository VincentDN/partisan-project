# Partisan Tactical, 3-D view (archived)

The original three.js top-down view of the convoy shooter. Deprecated: the RimWorld-style 2.5-D view
(`convoy/index.html`, `convoy/sprite-render.js`) is the base graphics system, and the 3-D page is no longer served
from `convoy/`. Kept here for reference only; its imports (`./sim.js`, `./levels/...`) point at `convoy/` and will not
resolve from this folder.
